# ZENVORA — Luxury Minimalist eCommerce Platform

An upscale fashion eCommerce storefront built with **Next.js (App Router)**, **TypeScript**, and a pure CSS design system (`app/globals.css`).

---

## Architectural Highlights

- **Framework**: Next.js (App Router, Server Components by default) + React 19 + TypeScript.
- **Design System**: Zero-dependency CSS architecture in `app/globals.css`. Uses CSS custom properties for warm off-white tones (`#faf8f5`), near-black (`#16130f`), hairline dividers (`#e5e0da`), Google Fonts (`Cormorant Garamond` + `Inter`), and GPU-accelerated micro-animations.
- **Persistent Cart**: Client-side React Context (`lib/store.tsx`) backed by `localStorage` with hydration safety checks to eliminate SSR mismatch flickers.
- **Interactive PDP**: Gallery thumbnails, strict size selection validation, quantity stepper, related items, and toast feedback.
- **Dynamic Catalogue**: Filter pills and category facets derive dynamically from active inventory via `subcategoriesFor()`.
- **Listings Pipeline**: Fully automated, dependency-free CSV + image processing pipeline (`npm run import-listings`).

## How to Swap `lib/api.ts` For Real Endpoints (The Backend Seam)

All pages and components in ZENVORA fetch data exclusively through the service layer in `lib/api.ts`.
Currently, these functions return Promises resolved against `lib/data.ts`.

To connect a live backend (Shopify Storefront API, Medusa, Commerce Layer, or custom REST/GraphQL):

1. Open `lib/api.ts`.
2. Replace the internal arrays queries with asynchronous fetch calls:
   ```ts
   // Example: Swapping getProducts for a REST API:
   export async function getProducts(options: GetProductsOptions = {}): Promise<Product[]> {
     const params = new URLSearchParams();
     if (options.category) params.set("category", options.category);
     if (options.subcategory) params.set("subcategory", options.subcategory);
     if (options.sort) params.set("sort", options.sort);
     if (options.query) params.set("q", options.query);

     const res = await fetch(`https://api.yourdomain.com/v1/products?${params}`, {
       headers: { "Authorization": `Bearer ${process.env.API_KEY}` },
       next: { revalidate: 60 } // Next.js ISR caching
     });

     if (!res.ok) throw new Error("Failed to fetch products");
     return res.json();
   }
   ```
3. Because all return types match `Promise<Product>` and `Promise<Product[]>`, **no page components, layouts, or listing views require modifications**.

## Running the Project

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).

### Production Build
```bash
npm run build
npm run start
```

### Importing Listings
```bash
# 1. Copy template
cp incoming/listings-template.csv incoming/listings.csv

# 2. Add product rows & drop images into incoming/images/

# 3. Run import
npm run import-listings
```
